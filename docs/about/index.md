# 关于艺境

## 项目介绍

**艺境 (ArtistWiki)** 是一个每日更新的书画艺术赏析百科，由 AI 自动生成中外著名画家、书法家的代表作品赏析。

## 数据来源

- 每日自动搜索艺术家及代表作品
- AI 生成专业赏析内容
- 同步发布到飞书文档和 GitHub Pages

## 技术栈

- **VitePress** - 静态站点生成
- **Vue 3** - 前端框架
- **GitHub Actions** - 自动部署
- **飞书 API** - 文档存储
