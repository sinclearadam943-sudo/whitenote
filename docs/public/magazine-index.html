关于 WhiteNote Magazine

WhiteNote Magazine 是 WhiteNote 文字花园的精选辑录。每期围绕一个主题，从网站海量内容中筛选出最具思想深度与文学价值的作品，以更具编辑性的方式呈现。我们不追求时效性，只关注那些经得起时间考验的思考与故事。
