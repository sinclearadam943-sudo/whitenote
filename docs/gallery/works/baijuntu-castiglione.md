# 百骏图

![百骏图](https://upload.wikimedia.org/wikipedia/commons/thumb/1/1a/One_Hundred_Horses_-_Giuseppe_Castiglione.jpg/1280px-One_Hundred_Horses_-_Giuseppe_Castiglione.jpg)

## 作品概览

《百骏图》是清代意大利籍宫廷画家**郎世宁**（Giuseppe Castiglione）的代表作，也是中国十大传世名画中**唯一一幅外国人的作品**。

| 属性 | 内容 |
|------|------|
| **创作者** | 郎世宁（Giuseppe Castiglione） |
| **创作年代** | 清雍正二年（1724年）开始，历时四年，于雍正六年（1728年）完成 |
| **材质** | 绢本设色（成品）；纸本白描（稿本） |
| **尺寸** | 纵94.5厘米，横776.2厘米（绢本成品）；纵94厘米，横789.3厘米（纸本稿本） |
| **现藏地** | 台北故宫博物院（绢本成品）；纽约大都会艺术博物馆（纸本稿本） |
| **艺术类别** | 中西合璧宫廷绘画 |

这幅长卷以长卷形式展开，全长约八米，共绘有**100匹姿态各异的骏马**和**11名牧马人**，描绘了骏马在草原上游牧放牧的宏大场景。画面从两棵参天老松树开始，透过松枝空隙可见牧马人搭建的白色帐篷，马匹或立或卧、或饮或嬉、或翻滚嬉戏、或打斗觅食，千姿百态，曲尽骏马之态。

## 艺术风格

《百骏图》是**中西绘画艺术完美融合**的典范之作，开创了一种全新的"中西合璧"画风。

### 核心特征

**1. 焦点透视与散点透视的融合**

郎世宁将西方的焦点透视法（单点透视）与中国传统绘画的散点透视相结合。画面采用高视平线构图，使空间极为辽远开阔——远处有雄伟的高山、起伏的丘陵，近处有平坦的草甸、苍劲的古木。河流蜿蜒其间，水泊平静如镜，展现出深远广阔的空间效果。

**2. 写实与写意的平衡**

- **西方写实技法**：注重解剖结构、光影效果和立体感。马匹的骨骼、肌肉、皮毛纹理刻画精准，通过明暗交界线突出体积感
- **中国写意精神**：弱化了强烈的明暗阴影，呈现出平光、漫射光效果，更符合东方审美特点

**3. 色彩与留白的和谐**

全幅色彩浓丽而不艳俗，马匹按名马毛色着彩，有轻有重、有浓有淡。同时巧妙地运用了中国画特有的留白技法，使画面具有平面感和呼吸感。

## 技法分析

### 笔墨技法

**马匹描绘**：
- 运用中国传统工笔画法，马匹轮廓遒劲，中锋作描
- 采用细密的短线，按照素描画法描绘马匹外形、皮毛皱褶
- 利用色泽深浅表现马匹的凹凸肌肉与体积感
- 马的眼神刻画生动传神，传达出不同情绪和神态

**背景处理**：
- **树木山石**：运用中国传统毛笔勾勒和皴法
- **草木植被**：松针、树皮、草叶等用墨线勾勒
- **光影渲染**：即使是马匹及树干上的阴影，也以中国传统渲染方法完成

### 构图特点

| 技法 | 表现 |
|------|------|
| 前重后轻 | 前景马匹浓墨重彩，背景渐虚 |
| 前实后虚 | 近景细节丰富，远景概括简炼 |
| 前大后小 | 通过比例变化营造空间深度 |
| 聚散有方 | 百匹骏马布局疏密有致，动静交融 |

画面自右至左，马匹人物聚散有序，山水树木错落有致，前、中、后景高低起伏，形成强烈的节奏感和韵律美。

## 历史背景

### 郎世宁来华

**1688年**，郎世宁出生于意大利米兰，原名**朱塞佩·伽斯底里奥内**（Giuseppe Castiglione）。年轻时在欧洲系统学习绘画，曾为教堂绘制圣像。

**1715年**（清康熙五十四年），郎世宁以天主教耶稣会修道士的身份来到中国传教。由于重视西洋技艺的康熙皇帝赏识，他被召入宫中，从此开始了长达**五十多年**的宫廷画家生涯。

### 创作契机

清雍正二年（1724年），郎世宁奉怡亲王允祥之命绘制《百骏图》。他深入观察皇家御苑中名马的骨骼结构和动态特征，经过**四年苦心创作**，于雍正六年（1728年）完成这一巨作。

### 三朝荣宠

郎世宁历经**康熙、雍正、乾隆三朝**，深受三位皇帝器重：
- **康熙**：召入宫中，开启宫廷画师生涯
- **雍正**：委托创作《百骏图》
- **乾隆**：见此画后盛赞为杰作，任命郎世宁为**宫廷首席画师**

郎世宁还参与了圆明园西洋楼的设计工作，并将欧洲的焦点透视画法传授给中国宫廷画家，为中西文化交流做出了卓越贡献。

### 递藏传奇

- **清代**：画作完成后一直收存于清宫，被编入《石渠宝笈·初编》
- **清末**：绢本成品从圆明园运出，后流传至台湾
- **现今**：绢本设色成品藏于**台北故宫博物院**；纸本白描稿本藏于**纽约大都会艺术博物馆**

## 艺术价值

### 1. 中西文化交流的见证

《百骏图》是18世纪中西文化交流最生动的注脚。郎世宁将欧洲文艺复兴时期的绘画技法带到中国，与中国传统笔墨相融合，开创了一种全新的绘画风格。这幅作品证明了不同文明之间的对话可以产生非凡的艺术成就。

### 2. 宫廷绘画的巅峰

清代是中国宫廷绘画的顶峰，而郎世宁正是这一时期无可争议的领袖人物。《百骏图》代表了清代宫廷绘画"中西合璧"的典型特征，体现了统治者对写实绘画的倡导和推崇。

### 3. 绘画技法的革新

- **对中国画的影响**：引入了西方解剖学、透视学和光影技法，推动了中国传统绘画向更加写实方向发展
- **对西方绘画的丰富**：在西方技法基础上融入中国画的留白、线条和晕染，丰富了表现手段

### 4. 历史与艺术的双重价值

作为"中国十大传世名画"中**唯一一幅外国人的作品**，《百骏图》不仅具有极高的艺术价值，更承载着特殊的历史意义——它记录了那个全球化初期东西方相遇的历史时刻。

### 后世评价

> "《百骏图》是郎世宁平生百余幅马作品中的杰作。全卷色彩浓丽、构图复杂、风格独特、别具意趣。"
> ——《石渠宝笈》

> "这幅八米长的画卷是中西融合的 ingenious integration（巧妙融合），展现了跨文化的艺术高度。"
> ——国际艺术评论界
