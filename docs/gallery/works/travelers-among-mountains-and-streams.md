## 一、作品概览

:::gallery-section

《溪山行旅图》是北宋画家范宽的代表作，被誉为"宋画第一神品"。这幅巨制绢本设色画以206.3厘米×103.3厘米的尺幅，气势磅礡地展现了关中山水的雄浑壮美。

| 项目 | 详情 |
|------|------|
| **中文名称** | 溪山行旅图 |
| **英文名称** | Travelers among Mountains and Streams |
| **艺术家** | 范宽（Fan Kuan） |
| **创作年代** | 约1000年（北宋初期） |
| **材质** | 绢本设色 |
| **尺寸** | 纵206.3厘米，横103.3厘米 |
| **收藏地** | 台北故宫博物院 |
| **作品类型** | 山水画 |

范宽（约950-1032年），原名中正，字中立，陕西华原（今陕西铜川耀州区）人。因其性情宽缓，人称"范宽"。他为人豪爽狂放，嗜酒论道，不受世事拘束，常年隐居终南山、太华山，观察北方山川的真实面貌，终成一代宗师。

1958年，台北故宫博物院研究员李霖灿在画幅右下角的树阴草丛间发现了"范宽"二字款识，终于确证了这幅作品的真迹身份。

:::

## 二、艺术风格

:::gallery-section

### 巨碑式山水

《溪山行旅图》最突出的艺术特色是其"巨碑式山水"构图——一座巍峨主峰占据画面三分之二的空间，顶天立地，几乎填满整个画面，极具视觉冲击力。这种构图打破了常规山水画的散点透视，以"迎面耸立"的姿态，将观者的视线直接引向巨峰，造成撼人心魄的效果。

画幅上部仅留出一线空白，透出远山一角，顿觉全画通透；右侧一道飞瀑飞流直下，水雾蒸腾，为厚重的山体增添了一丝灵动之气，形成"刚健含婀娜"的审美张力。

### 北方山水典范

范宽发展了荆浩、关仝开创的北方山水画派，与关仝、李成并列，被宋人誉为"三家鼎峙，百代标程"。宋人刘道醇评价："董源得山之神气，李成得山之体貌，范宽得山之骨法。"

范宽的山水画呈现"远望不离座外""峰峦浑厚，势壮雄强"的视觉效果，以雄强浑厚、峻重老苍著称。他与李成一文一武，为中国山水画注入阳刚之气，开创了雄浑之境。

:::

## 三、技法分析

:::gallery-section

### 雨点皴法

范宽在《溪山行旅图》中独创"雨点皴"（又称"豆瓣皴""钉子皴"）技法——用细密的短笔触，如雨点般密集地描绘山石纹理。这些皴法密集如雨，积点成面，将北方山石的坚硬质感和厚重体积表现得淋漓尽致。

北宋郭若虚在《图画见闻志》中称之为"抢笔俱均"——范宽画山时，先作轮廓，再以无数短条皴布满轮廓内外，短条之间的距离几乎相等，形成极具秩序感的视觉效果。

### 用墨特点

范宽用墨酣畅淋漓，质朴浑厚。画中山石以浓墨勾出轮廓和石骨，再以淡墨作皴法，层层渲染，苍苍茫茫。山头以浓墨焦墨密点树林，郁郁葱葱，重量感十足。树丛前后用墨不同——近者浓淡相间，远者苍茫一片，皆给人以苍郁朴茂之感。

### 构图层次

画面可分为近景、中景、远景三个层次：

- **近景**：巨石横卧，直逼眼际，山径溪谷掩映其间，一队骡马商旅由左侧穿林而来
- **中景**：峰峦对峙，林木丛密，隐约可见飞殿楼阁涌出峰树之颠
- **远景**：主峰耸立，几乎占据全幅三分之二，气势磅礴，如擎天巨柱

人物与山体的比例形成强烈对比——小小商旅在巍峨大山面前显得格外渺小，展现了自然的崇高与人类的谦卑，隐含"天人合一"的哲学思想。

:::

## 四、历史背景

:::gallery-section

### 北宋绘画的黄金时代

北宋（960-1127年）是中国绘画史上的黄金时代。在这一时期，山水画从人物画的背景中独立出来，成为独立的画科，并达到前所未有的高度。宋代的皇家画院制度完善，绘画受到皇室的高度重视，艺术氛围空前繁荣。

### 文人画的萌芽

范宽提出的艺术主张"师古人不如师造化，师造化不如师心源"，成为后世文人画理论的滥觞。他认为："前人之法，未尝不近取诸物。吾与其师于人者，未若师诸物也。吾与其师于物者，未若师诸心。"

这一理念构建了"师人→师物→师心"的渐进式艺术观——与其模仿前人，不如直接向自然学习；与其机械描摹自然，不如用心去感悟和创造。这既是学画的方法论，也点明了艺术的真谛：源于自然，高于自然。

范宽隐居终南、太华山，"常危坐终日，纵目四顾，以求其趣。虽雪月之际，必徘徊凝览，以发思虑"，将真山水的观察与个人心境的感悟融为一体。

:::

## 五、艺术价值与影响

:::gallery-section

### 历代评价

- **米芾**《画史》："范宽山水丛丛如恒岱，远山多正面，折落有势。山顶好作密林，水际作突兀大石，溪山深虚，水若有声。物象之幽雅，品固在李成上，本朝自无人出其右。"

- **董其昌**：推崇南宗的明董其昌也评此画为"宋画第一"，可见范宽艺术成就之高。

- **徐悲鸿**："中国所有之宝，吾所最倾倒者，则为范中立《溪山行旅图》，大气磅礴，沉雄高古，诚辟易万人之作。此幅既系巨帧，而一山头，几占全幅面积2/3，章法突兀，使人咋舌！"

### 对后世的影响

范宽的画风对后世影响极大，与李成、董源二人合称"宋三家"：

- **元四家**（黄公望、吴镇、倪瓒、王蒙）皆受其影响
- **明代唐寅**、**沈周**等吴门画派画家
- **清代"金陵画派"**
- **近代黄宾虹**等大师

《溪山行旅图》不仅是中国古代山水画的巅峰之作，更代表了北宋山水画的最高成就。它的大山大水全景构图、细致刻画的山石树木、多变的笔墨技法以及雄浑的意境，冲击着观者的心灵，使人产生无尽的凝思。

:::
