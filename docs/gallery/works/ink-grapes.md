# 徐渭《墨葡萄图》赏析

**徐渭**（1521—1593），初字文清，后改字文长，号青藤老人、天池山人等，浙江绍兴人。明代著名文学家、书画家、戏曲家、军事家。与解缙、杨慎并称"明代三才子"，是中国"泼墨大写意画派"创始人，"青藤画派"之鼻祖。

---

## 一、作品概览

| 项目 | 内容 |
|------|------|
| **作品名称** | 《墨葡萄图》 |
| **英文名称** | *Ink Grapes* |
| **作者** | 徐渭（Xu Wei） |
| **创作年代** | 明代（约1576年，55岁左右） |
| **材质** | 纸本水墨 立轴 |
| **尺寸** | 116.4cm × 64.3cm |
| **现藏地** | 北京故宫博物院 |
| **作品类型** | 大写意花鸟画 |

《墨葡萄图》是徐渭晚年最具代表性的传世名作之一，也是中国大写意花鸟画发展史上的里程碑式作品。画中一架葡萄从画面右侧斜穿而出，老藤错落低垂，串串葡萄倒挂枝头，晶莹欲滴，茂叶以大块水墨点染而成。画面左上角有徐渭自题诗一首：

> **"半生落魄已成翁，独立书斋啸晚风。**
> **笔底明珠无处卖，闲抛闲掷野藤中。"**

款识"天池"，钤"湘管斋"印。此画经清代李佐贤、陈希濂等鉴藏，现藏于北京故宫博物院。

---

## 二、艺术风格

徐渭的《墨葡萄图》开创了中国水墨大写意花鸟画的全新风格，其艺术特色主要体现在以下几个方面：

### 1. 不求形似求生韵

徐渭提出"不求形似求生韵"的艺术主张，彻底打破了传统工笔花鸟画的束缚。画中的葡萄、叶片并不追求细节上的逼真再现，而是通过笔墨的挥洒和构图的安排，传达出一种野拙的生机和动人的气势，达到"似与不似之间"的最高境界。

### 2. 泼墨淋漓的豪放气概

此图纯以水墨写葡萄，以饱含水分的泼墨写意法，点画葡萄枝叶，水墨酣畅。葡萄珠的晶莹透彻之感，以淡墨与浓墨配合，随意交织曲转，淋漓酣畅地表现出来。茂盛的叶子以大块水墨点成，信笔挥洒，任乎性情，意趣横生。

### 3. 诗书画印的完美融合

画面将狂放的草书用笔、泼墨大写意的绘画技法与题画诗有机结合。题诗书法线条跌宕起伏、不拘小节，字势欹斜跌宕，用笔大胆泼辣，与画面葡萄藤蔓的动势相互呼应，形成了诗、书、画、印四位一体的综合艺术表现。

### 4. 狂傲不羁的个性表达

画中表现出一种疯颠之态和超越理性法度的狂逸韵致。正如评论家所言，"画到精神飘忽处，更无真相有真魂"。徐渭借葡萄这一寻常蔬果，抒发了自己怀才不遇、抱负难酬的悲愤与抗争。

## 三、技法分析

### 构图布局

画面构图大胆突破传统，整体采用三角形布局：
- **右侧主体**：葡萄老藤从画面右方斜穿至左面而出，由老枝生出欹斜藤蔓，倾泻出墨叶和墨点
- **左侧平衡**：题诗与垂落的藤蔓相互呼应，起到平衡画面的作用
- **留白处理**：画面中部大量留白，呈倒斜三角形，右下角还有一小块留白，符合中国画"计白当黑"的传统美学

### 笔墨技法

| 元素 | 技法 | 效果 |
|------|------|------|
| **藤蔓** | 草书笔法飞动，线条纷披错落 | 老藤遒劲有力，向下低垂 |
| **叶片** | 泼墨法，大块水墨点染 | 茂叶酣畅，湿润欲滴 |
| **葡萄果实** | 淡墨与浓墨配合，点染成串 | 晶莹剔透，鲜嫩欲滴 |
| **整体** | 干笔、湿笔、破笔兼用 | 墨气淋漓，浑然天成 |

徐渭是**第一个采用生宣纸作画**的画家，生宣纸良好的吸水性便于他即兴挥洒，使墨色变化更加丰富自然。

### 用墨特点

- **墨分五色**：以墨代色，通过浓淡干湿的变化表现葡萄的晶莹剔透
- **泼墨与破墨**：大胆使用泼墨法，任水墨自然渗化；再以破墨法增强层次
- **以书入画**：将狂放的草书用笔融入花鸟画创作，用笔似草书之飞动

## 四、历史背景

### 徐渭坎坷的一生

徐渭生于明正德十六年（1521年），一生坎坷多舛，有人以"十字歌"概括：

> **一生坎坷，二兄早亡，三次结婚，四处帮闲**
> **五车学富，六亲皆散，七年冤狱，八试不售**
> **九番自杀，十（实）堪嗟叹！**

| 时期 | 经历 |
|------|------|
| 幼年 | 出生百日丧父，生母十岁被逐出家门 |
| 青年 | 六岁读书，九岁能文，被誉为"神童"；二十岁中秀才，此后八次乡试均落第 |
| 壮年 | 1558年入胡宗宪幕府，参与抗倭策划，屡出奇谋；1562年胡宗宪因严嵩倒台被牵连自杀，徐渭恐惧受牵连 |
| 疯癫 | 多次自杀未遂：用斧击头、以钉刺耳、锤击肾囊；后因猜忌误杀继妻张氏入狱七年 |
| 晚年 | 53岁经友人营救出狱，贫病交加，靠卖字画度日，73岁在破草屋中去世，仅一狗相伴 |

### 创作背景

约1576年夏天，55岁的徐渭应宣府巡抚吴兑之邀前往宣府。宣府自古盛产葡萄，徐渭看着架上的葡萄，联想到自己的半生蹉跎——八次科举不第、幕府生涯破灭、牢狱之灾、贫病交加——于是泼墨创作了这幅千古名画，并挥毫写就了题图诗。画中的葡萄如同明珠被闲抛在野藤中，无人问津，正是画家自身怀才不遇、愤懑不平心境的真实写照。

### 时代背景

明代中晚期，社会经济繁荣与市民文化兴起推动了绘画风格多元化发展。在吴门画派文雅纤弱的主流风格之外，徐渭以其强烈的情感表达开创了泼墨大写意画风，成为水墨写意花鸟画的重要变革者。他将写意法演变为大写意法，真正达到了"逸品"和文人画所追求的"逸笔草草，不求形似"的高度。

## 五、艺术价值

### 1. 中国写意花鸟画的里程碑

徐渭的《墨葡萄图》把中国写意花鸟画推向了能够强烈抒写内心情感的极高境界，将生宣纸上笔墨的表现力提高到前所未有的水平，成为中国写意花鸟画发展中的里程碑。正如艺术史家所言，"自宋元以来，写意花鸟画就有一定的发展，但真正能够发挥中国画笔墨纸张特殊效果而创立了水墨大写意画法的，应该归功于徐渭。"

### 2. 开创"青藤画派"

徐渭创立的水墨大写意花鸟画风，从根本上完成了变革，开创了"青藤画派"。他的画风深刻影响了后世：
- **清代**：八大山人、石涛、扬州八怪
- **近现代**：吴昌硕、齐白石

郑板桥曾刻一印，自称"青藤门下走狗"；齐白石更是感叹"恨不生三百年前，为诸君磨墨理纸"，并赋诗"青藤雪个远凡胎，缶老衰年别有才。我愿九原为走狗，三家门下转轮来。"

### 3. 文人画精神的极致体现

《墨葡萄图》将文人画"寄兴遣怀"的精神追求发挥到极致。画家不是为画葡萄而画葡萄，而是借葡萄抒写自己"英雄失路，托足无门"的悲愤与历劫不磨的旺盛生命力。画中虽为花草瓜果，却具有磅礴奇崛的气势和雄肆豪放的格调。

### 4. 跨文化比较价值

艺术评论家郑为曾将徐渭与西方后印象派画家凡·高相提并论："虽然在时代、地域、生活学养和艺术情趣上，徐渭与之不同。但贫穷潦倒，顽疾缠身下，疯狂地献身于艺术的纯真却又何等相似。"
